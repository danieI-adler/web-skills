# Web Skills Repository 🚀

A curated collection of web development skills, design engineering patterns, interaction guides, and top-tier resources to build world-class websites.

---

## 🎨 In-House Core Skills

- **[skills/human-grade-web-design](./skills/human-grade-web-design)** – Diretrizes definitivas e princípios operacionais para criar websites e landing pages com acabamento de produto sênior (direção de arte com 20 anos de experiência). Elimina o  slop de IA (emojis cafonas, gradientes roxos genéricos, cantos hiper-arredondados, falta de hierarquia tipográfica e SEO).
- **[skills/generative_ui](./skills/generative_ui)** – Renderização de widgets interativos em tempo real, diagramas, controles visuais e UI dinâmica.
- **[skills/ponytail](./skills/ponytail)** – Filosofia de engenharia enxuta: máxima simplicidade funcional, corte de boilerplate desnecessário, adoção de APIs nativas/web standards antes de bibliotecas pesadas.
- **[skills/remix.run.md](./skills/remix.run.md)** – Arquitetura web moderna full-stack, SSR e padrões de dados.

## 🧠 Emil Kowalski Design & Animation Skills

Especialização em design engineering e micro-interações:

- **skills/animate** – Princípios de animação de UI fluida, orquestração e transições.
- **skills/animate-expo** – Animações nativas para apps com React Native / Expo.
- **skills/animation-vocabulary** – Física de molas (springs), curvas de aceleração e vocabulário de movimento.
- **skills/apple-design** – Human Interface Guidelines e micro-interações no padrão Apple.
- **skills/ask-sonner** – Padrões de arquitetura para notificações flutuantes e toasts (criador do Sonner).
- **skills/emil-design-eng** – Princípios e filosofia de Design Engineering.
- **skills/find-animation-opportunities** – Como identificar interfaces estáticas que se beneficiam de animação.
- **skills/improve-animations** – Diagnóstico de jank, otimização de frame rates e ajuste fino de springs.
- **skills/mobile-native** – Gestos e interações por toque mobile-first.
- **skills/pick-ui-library** – Matriz de decisão para escolher a biblioteca de UI ideal.
- **skills/prototype** – Técnicas de prototipação rápida para web e mobile.
- **skills/review-animations** – Checklist de code review para animações em PRs.
- **skills/write-swift** – Componentes e interações Swift UI.
