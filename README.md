# Web Skills Repository 🚀

A curated collection of web development skills, design engineering patterns, interaction guides, and top-tier resources to build world-class websites.

---

## 🧠 Skills Included

Includes all specialized animation and interaction engineering skills from [Emil Kowalski](https://github.com/emilkowalski/skills), plus full-stack architecture patterns:

- **skills/animate** – Principles of smooth UI animations, choreographies, and transitions.
- **skills/animate-expo** – Native mobile animations with React Native / Expo.
- **skills/animation-vocabulary** – Physics, spring dynamics, easing curves, and timing vocabulary.
- **skills/apple-design** – Apple human interface guidelines, micro-interactions, and aesthetics.
- **skills/ask-sonner** – Toast and floating notification design patterns (creator of Sonner).
- **skills/emil-design-eng** – Emil Kowalski design engineering principles and philosophies.
- **skills/find-animation-opportunities** – How to spot static UI areas that benefit from animation.
- **skills/improve-animations** – Diagnosing jank, optimizing frame rates, and tuning springs.
- **skills/mobile-native** – Mobile-first native gestures and touches.
- **skills/pick-ui-library** – Framework to pick the right UI library for your project.
- **skills/prototype** – Rapid prototyping techniques for web and native interfaces.
- **skills/review-animations** – Animation review checklist for PRs and design reviews.
- **skills/write-swift** – Swift UI interaction building blocks.
- **skills/remix.run.md** – Full-stack React architecture, SSR, and web standards.
